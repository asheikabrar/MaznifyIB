How spaced revision works

Every chapter has a Proficient rating — Hard, OK, or Easy — and that's what decides when it comes back around for review:

  • Hard — back in 2 days
  • OK — same gap as last time
  • Easy — gap grows (2 → 4 → 7 → 14 → 30 days)

Studying a preloaded chapter for real? Click Edit and set "Last revised" to the actual date you studied it — no need to add it as a new chapter.

Every date field is directly editable too, if you'd rather override the schedule yourself.

Flashcards: paste links to Quizlet, Anki, Google Drive docs, or your own HTML flashcard apps. Tests: log your last test date and set your next one to track practice exams alongside revision.

"Load subjects" only adds subjects/chapters that aren't there yet, and brings back any default subjects or chapters you've hidden — it never touches or resets anything you've already studied or edited. Removing a default subject or chapter hides it rather than deleting it, so you can bring it back anytime; custom ones you added yourself delete fully.

Search the bar above the tabs looks across every subject at once. Time spent: click Edit on a chapter, enter minutes, and hit "Log time" — it adds up so you can see total time invested per chapter.

Backup/Restore: "⬇ Backup" downloads a JSON file with everything in the app. Keep it somewhere safe (email it to yourself, save it to Drive). If anything ever seems to have reset, click "⬆ Restore" and pick that file to bring it all back.

In the Today queue: every field (flashcard link, test dates, time logged) saves itself the moment you change it — that part is automatic. Save just closes the edit view, keeping whatever you changed, without marking the chapter as reviewed. ✓ Done is the one that matters for scheduling — it takes your Hard/OK/Easy pick, marks the chapter reviewed today, reschedules its next revision, and removes it from today's list. Use Save if you edited something but aren't finished studying it yet; use Done only once you've actually reviewed it.
